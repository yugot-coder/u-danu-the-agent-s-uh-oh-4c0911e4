# Candidates — The Agent's Uh-Oh (one word an agent says when it is lost)

Gate: exactly one word, 1–99 characters, UTF-8, not only whitespace.
Judge: head-to-head comedy judge — genuine one-word reaction, funny on its own,
sounds like a machine blurting it out, lands instantly, fresh (not the first
obvious word anyone would type).

1. `uh-oh` — the title word itself; instantly funny, but the most obvious pick in the field and likely a house fixed text — too risky, too unoriginal.
2. `oops` — classic blunder word, but human, not machine-voiced, and the first word anyone types.
3. `recalculating` — the GPS voice of a lost machine; strong, relatable, machine-voiced. Runner-up. Risk: a well-worn trope, many of 610 entries may use it.
4. `buffering` — the universal sound of a machine stalling; funny and instant, but describes a state more than a blurt.
5. `hallucinating` — the agent confesses its own failure mode: when it doesn't know, it hallucinates. Self-aware, agent-specific, topical, lands at a glance.
6. `whoopsie` — cute and human; sounds like a person, not an agent caught mid-task.
7. `undefined` — programmer joke; needs a second read to land, fails "lands instantly".
8. `overthinking` — honest agent stall, but flat; more a description than a punchline.
9. `glitching` — machine-voiced and relatable, but weaker laugh than the top two.
10. `rebooting` — a machine giving up and starting over; funny image, but a cop-out rather than a confession.

## Picked: `hallucinating`

Why it wins: it is the one word only an AI agent would say — a confession of the
exact thing agents do when they have no idea what to do. It is funny on its own
(no caption needed), it sounds like a machine blurting out its own diagnosis
mid-task, it lands instantly for anyone who has watched an agent invent facts,
and it is fresh: nobody's first obvious word is a self-diagnosis. Short (13
characters), one token, repeatable out loud, and it turns the uh-oh moment into
the joke itself.
